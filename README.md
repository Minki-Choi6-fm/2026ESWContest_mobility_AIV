# AIV — 대형차-승용차 상호 안전거리 경고 시스템

> 제24회 임베디드SW경진대회 · 자동차/모빌리티 부문 · 팀 **AIV** (세종대학교)

후방의 대형차가 레이더·카메라·IMU·OBD·GPS로 앞차와의 위험을 판단하고, **자차 운전자에게 경고하는 동시에 V2V(ESP)로 전방 승용차 운전자에게도 경고를 전달**하는 쌍방향 안전거리 경고 시스템입니다.

## 1. 문제와 목표

대형차는 적재 하중 때문에 제동거리가 길어 즉시 감속하기 어렵습니다. 앞 승용차 운전자는 뒤 차의 제동 한계를 모른 채 급감속·급정지하기 쉽고, 뒤 대형차 운전자는 늦게 알아차리면 추돌로 이어집니다.
이 작품은 **두 운전자 모두에게 위험을 미리 알리는 것**을 목표로 합니다.

| 목표 | 내용 |
|---|---|
| 쌍방향 경고 | 후방 차량이 위험을 판단해 V2V(BSM 26 B, 10 Hz)로 양쪽 운전자에게 경고 |
| 동적 경고 시점 | 속도와 제동 특성(제동계수 K)을 반영한 충돌예상시간(TTC)·필요 감속도 기준으로 주의/위험 단계 판정 |
| 안전 우선 설계 | 레이더 CAN 프레임이 1000 ms 동안 수신되지 않으면 Safe Mode로 전환 |
| 확장 구조 | 경량 BSM과 통신 계층 분리로 V2X·C-ITS 연동을 염두에 둔 구조 |

> 실험은 승용차를 후방 "대형차" 역할로 사용했습니다.

## 2. 시스템 구성

```
 후방 차량 (대형차 역할)                              전방 차량 (승용차)
┌─────────────────────────────┐                  ┌────────────────────────────┐
│ MR76 레이더 ─SPI CAN┐         │                  │ RPi4  (V2V 수신·경고 판단)    │
│ IMU · OBD ──────────┤         │                  │   │ UART                  │
│               NUCLEO-F446RE │   BSM 26 B        │ NUCLEO-F446RE (경고 처리)   │
│               (센서·실시간 안전)│   ESP-NOW 10 Hz   │   │                       │
│                  │ UART      │ ◄──────────────► │ OLED (I2C) · 부저(GPIO)     │
│ RealSense D435i ─┤           │                  │ ESP32 V2V 브릿지            │
│ GPS ─────────────┤           │                  └────────────────────────────┘
│ Raspberry Pi 5 (판단·인식)    │
│   YOLOv8n · 목표 선택 · 위험 판단 │
│   부저(GPIO26) · BSM 생성      │
│ ESP32 V2V 브릿지 (USB 시리얼)   │
└─────────────────────────────┘
```

| 차량 | 구성 |
|---|---|
| 후방 (대형차 역할) | Raspberry Pi 5, STM32 NUCLEO-F446RE, MR76 레이더(SPI CAN), Intel RealSense D435i, IMU, OBD-II, GPS, 부저, ESP32 |
| 전방 (승용차) | Raspberry Pi 4, STM32 NUCLEO-F446RE, OLED(I2C), 부저, ESP32 |
| 측면 (검증용) | Raspberry Pi 4, OLED, 부저, ESP32 — 옆 차선 차량에 대한 **오경고 검증용** |

**역할 분담**

- **STM32** : 레이더·IMU·OBD 수신, 센서 프레임을 Pi로 전달, 독립 워치독(IWDG), Safe Mode
- **Raspberry Pi 5** : 영상 인식(YOLOv8n), 목표(앞차) 선택, 위험 판단, 부저, BSM 생성
- **ESP32** : Pi와 USB 시리얼로 연결되는 ESP-NOW 송수신 브릿지

## 3. 위험 판단 방식

1. **TTC (충돌예상시간)** = 거리 ÷ 접근속도
2. **필요 감속도** : 앞차와 부딪히지 않기 위해 필요한 감속(g). 제동계수 **K** 기준의 한계와 비교합니다.
3. 아래 중 하나라도 만족하면 단계를 올립니다.

| 단계 | 의미 | 동작 |
|---|---|---|
| 0 | 안전 | — |
| 1 | 주의 (CAUTION) | 화면 표시만 |
| 2 | 위험 (DANGER) | 부저 + V2V 경고 BSM |
| 0xFF | 알 수 없음 | — |

- 기본 TTC 기준 : 위험 < 2.0 s, 주의 < 3.0 s (환경변수 `TTC2_S`, `TTC1_S`로 변경, 시연은 3.0 s / 4.0 s)
- 부저는 위험 단계에서만, 그리고 **자차 속도를 알고 있을 때만** 울립니다.
- 정차·정지 물체·대향 차량 등에 대한 억제 규칙과, 옵션형 횡방향 제한(`LAT2_MAX_M`, `PASS_D_M`, `PASS_LAT_M`)이 있습니다. 옵션은 기본값에서 꺼져 있습니다.
- **K(제동계수)** : IMU 가속도와 OBD 속도로 추정하는 모듈이 있으며 **현재 검증 중**입니다. `K_FIXED`(또는 `--k-fixed`)로 판단에 쓰는 값을 고정할 수 있고, 이때 추정 모듈은 관찰용으로만 돌아갑니다.

## 4. V2V 통신 (BSM)

- 전송 : ESP-NOW 브로드캐스트, **10 Hz**, 26 바이트, **CRC-16**
- 필드 : SYNC · VERSION · VEHICLE_ID · SEQ · TIMESTAMP · LAT · LON · SPEED · HEADING · K_VALUE · STATUS · CRC-16 · END
- STATUS 비트에 `DANGER_ACTIVE`, `BRAKE_ACTIVE` 등이 있습니다.
- 개발·시험 중에는 UDP 전송도 지원합니다(`TRANSPORT=udp`).
- 전방 차량은 GPS로 "내 뒤에 있는 차량인지" 판별해 경고를 걸러 냅니다.

## 6. 실행 방법

### 후방 (Raspberry Pi 5)

```bash
cd ~/ESWContest_ws
OUT=logs/car_test/road_$(date +%m%d_%H%M); mkdir -p "$OUT"
K_FIXED=0.5 TTC2_S=3.0 TTC1_S=4.0 TARGET_SEL=win SNAP_EVERY_S=1 \
TRANSPORT=esp-now BUZZER=real RADAR_POWER=direct12v \
bash tools/run_car_test.sh 2>&1 | tee "$OUT/terminal.txt"
```

- 시작 전 점검(서비스, 포트, GPS fix, 카메라, ESP32, 설정값)을 먼저 수행하고, 결과를 화면에 표시합니다.
- 종료는 `Ctrl+C`이며 부저와 경고는 자동으로 꺼집니다.
- `STATUS_LINE=1`을 켜면 1초마다 거리·접근속도·TTC·필요 감속도·단계를 한 줄로 출력합니다.

### 전방 (Raspberry Pi 4) / 측면 (Raspberry Pi 4)

각 브랜치의 README를 참고하세요.

### 주행 로그

실행할 때마다 `logs/car_test/road_MMDD_HHMM/`에 아래 파일이 생성됩니다.

| 파일 | 내용 |
|---|---|
| `drive_log.csv` | 20 Hz 주행 기록 (거리, 접근속도, TTC, 단계, 자차 속도, 필요 감속도 등) |
| `output_sink.csv` | 경고 출력 기록 |
| `bsm_tx.csv` | 송신한 BSM 기록 |
| `rx_stats_*.csv` | STM32↔Pi 통신 통계 (손실률, CRC 오류, STM32 리셋 횟수) |
| `terminal.txt` | 실행 시 터미널 출력 |
