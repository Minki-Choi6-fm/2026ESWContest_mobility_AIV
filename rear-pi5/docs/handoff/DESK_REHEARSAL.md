# 책상 리허설 (S11-b) — 레이더만, 실제 STM32 입력을 읽기 전용으로

## 상태: **준비 완료, 실제 5분 실행은 아직 안 함** (사용자가 "시작"이라고 답할 때만 실행)
## 1. 실행 방법이 이미 있는가 / 포트 충돌 확인
- `pipeline_main.py` 가 실제 포트를 읽기 전용으로 열 수 있으나 BSM 을 UDP 로 **송신**(기본 루프백)하므로, "BSM 은 보내지 말 것"에 맞춰 **새 도구 `pi5/pipeline/desk_rehearsal.py`** 를 만들었다: `O_RDONLY` 로만 열고, 전송 소켓을 만들지 않으며, BSM 은 로컬에서 만들고 다시 디코드만 한다. 부저는 mock.
- 충돌: `/dev/ttyAMA2` 를 잡고 있는 프로세스는 **ego_speed_tx.py (PID 648, 쓰기 전용 서비스)** 하나뿐(`fuser`/preflight 확인). 읽기와 쓰기는 서로 다른 방향이라 충돌하지 않는다(S2.5 의 30 s 실측에서도 같은 구성으로 읽음). 다만 **읽는 프로세스는 하나만**이어야 하므로 로거/다른 리시버가 켜져 있으면 `desk_rehearsal.py` 가 스스로 **실행을 거부**한다(READ-ONLY, 서비스 건드리지 않음).
- 가짜 STM32(pty)로 10 s 사전 시험 완료: 수신 0x10/0x12/0x13 정상, 갱신 19.7회/s, 도착→레벨 계산 지연 p50 20 ms / p90 47 ms (이 값은 가짜 입력 기준이며 실제 값이 아님).
## 2. 실행 명령 (사용자가 "시작"이라고 답한 뒤에만)
```
python3 -I ~/ESWContest_ws/pi5/pipeline/desk_rehearsal.py --duration 300 --out ~/ESWContest_ws/logs/desk_rehearsal/$(date +%Y%m%d_%H%M%S)
```
사용자는 레이더 앞에서 금속판/몸을 움직인다. 출력: `rehearsal.csv`(20 Hz: 레벨, reason, 타깃 id/거리/횡/상대속도, 속도 출처, 0x10 상태, radar_alive, BSM STATUS 바이트), `summary.json`(레벨 분포, reason 분포, 지연 p50/p90/max, 초당 갱신, 0x10 gap, Safe Mode 진입 수, 초당 0x12/0x10 개수, 부저 mock 전환 수).
- 기록 구분 규칙: **Safe Mode/0xFF 진입은 전원 처짐 의심으로 따로 표시**한다. 레이더 전원 처짐(약 5.5 s 주기, 1.5 s 끊김)이 있으면 `per_second_0x12`/`0x10 gap`에 주기적 구멍이 나타난다. 이 구멍과 겹치는 Safe 진입은 **레이더/알고리즘 문제가 아니라 전원 영향 가능성이 높은 것으로** 해석한다(확정 아님).
## 3. 자차 속도를 모를 때 규칙별 동작 (합성 입력, `danger.assess` 직접 호출, 사실)
OBD/GPS 모두 없음 → `v_r = None`. 비교용으로 `v_r = 0 km/h`(정차를 알 때)도 같이 계산했다. K_r=0.5, K_f=0.8.
| 상황 | 속도 모름 | 속도 0 km/h |
|---|---|---|
| 판이 3 m 에서 −2 m/s 로 접근 (dyn 0) | **level 2** (TTC 1.5 s) | level 1 (정차 억제 → 최대 주의) |
| 같은 접근, 레이더 dyn=1(정지물 분류) | level 1 (정지 물체 억제) | level 1 |
| 판이 3 m 에 정지 | 0 | 0 |
| 판이 1.5 m 에 정지 | **0** (d_req 항 제외) | 1 (d_req(1.0 s)=2.0 m 이내) |
| 6 m, −3 m/s (TTC 2.0) | 1 | 1 |
| 8 m, −3 m/s (TTC 2.7) | 1 | 1 |
| 멀어짐 | 0 | 0 |
규칙별로 정리하면:
- **정지 상태 최대 주의(<2 km/h)**: `v_r` 이 있어야 적용 → **속도 모름이면 적용 안 됨** (가까이서 빠르게 다가오는 판이 level 2 = 부저 후보까지 감).
- **지면 고정(|vrel+v_r|≤1.5)**: `v_r` 필요 → 속도 모름이면 계산식 적용 안 됨. 단 레이더 `dyn` 이 정지(1)이면 속도와 무관하게 최대 주의로 제한.
- **근거리 제한(implausible headway d/v<0.3 s)**: `v_r` 필요 → 속도 모름이면 적용 안 됨.
- **마주오는/추월 차**: `v_r` 필요 → 적용 안 됨.
- **d_req(1.0 s) 거리 항**: `v_r` 필요 → 제외, 근거리 정지 물체가 caution 이 되지 않음. TTC/필요 감속도 항은 그대로.
→ 책상에서 판을 빠르게 레이더 쪽으로 움직이면 속도 모름 상태에서 level 2(mock 부저 ON)가 쉽게 나온다. 차에서는 속도가 있으므로 정상 동작과 다르다. **결정 필요**: 속도 모름일 때 정차를 가정해 억제할지(오경보↓, 누락 위험↑) 지금처럼 둘지.
